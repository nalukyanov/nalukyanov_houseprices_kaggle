# House Prices

Учебный проект для сравнения моделей регрессии на данных House Prices. Модели предсказывают `log1p(SalePrice)` — натуральный логарифм цены дома плюс один. Оценка проводится на пяти фолдах `KFold` с перемешиванием и `random_state=13`.

## Установка

Текущее локальное окружение использует Python 3.14.4. В `requirements.txt` зафиксированы версии прямых зависимостей из этого окружения; транзитивные зависимости устанавливаются автоматически. Пакеты для Jupyter не входят в зависимости запуска проекта.

Из корня проекта в Bash или Zsh:

```bash
bash setup.sh
source .venv/bin/activate
```

Скрипт создаёт `.venv`, устанавливает зависимости и проверяет их через `pip check`. Для создания окружения используется `python3`. Можно вызвать скрипт из другой папки, указав путь к `setup.sh`: окружение создаётся в каталоге проекта. При ошибке установка останавливается.

## Данные и запуск

Поместите обучающий датасет в `raw_dataset/train.csv`. Он должен содержать признаки House Prices и целевую колонку `SalePrice`. Файлы `test.csv` и `sample_submission.csv` текущий код не использует: он сравнивает модели по кросс-валидации, не сохраняет обученные модели и не создаёт submission.

Одна модель:

```bash
python src/main.py -m simpletree
```

Несколько моделей:

```bash
python src/main.py -m logreg knn catboost
```

Все модели, включая нейросеть:

```bash
python src/main.py -m all
```

Без `-m` также запускаются все модели. Справка: `python src/main.py --help`.

| Аргумент `-m` | Модель |
|---|---|
| `logreg` | Ridge — линейная регрессия с L2-регуляризацией |
| `knn` | KNeighborsRegressor |
| `simpletree` | DecisionTreeRegressor |
| `randforest` | RandomForestRegressor |
| `xgboost` | XGBRegressor |
| `lightgbm` | LGBMRegressor |
| `catboost` | CatBoostRegressor |
| `nn` | Полносвязная нейросеть на PyTorch |

Имя `logreg` сохранено в интерфейсе и конфиге, но под ним запускается Ridge. Пути, списки признаков и гиперпараметры находятся в `src/config.py`.

## Подготовка данных и обучение

Перед обучением программа создаёт выходные каталоги и пересоздаёт подготовленные данные:

- Удаляет `Id`, преобразует порядковые признаки по словарям из `src/columns_specification.py` и заполняет заданные группы пропусков.
- Сохраняет вариант с категориальными признаками для CatBoost в `preprocessed_data/preprocessed_data.csv`.
- Сохраняет вариант с one-hot-кодированием для остальных моделей в `preprocessed_data/one_hoted_data.csv`.

Оставшиеся числовые пропуски заполняются средними, вычисленными на обучающей части каждого фолда. Для Ridge и KNN числовые признаки масштабируются через `StandardScaler`. Для нейросети масштабируется вся матрица признаков после one-hot-кодирования. Скейлеры также обучаются только на обучающей части фолда.

Нейросеть обучается с `MSELoss`, оптимизатором AdamW и early stopping по валидационному MSE. Для оценки восстанавливается состояние с лучшим валидационным loss. Тот же валидационный фолд используется для выбора эпохи и итоговой оценки, что может делать оценку нейросети оптимистичной.

## Метрика и результаты

Для всех моделей считается положительный RMSE по `log1p(SalePrice)`:

```text
sqrt(mean((pred_log_price - log1p(SalePrice)) ** 2))
```

Чем меньше значение, тем лучше. Это ошибка в логарифмической шкале, а не доллары и не проценты. В sklearn отрицательные значения `neg_root_mean_squared_error` меняют знак перед выводом; нейросеть непосредственно вычисляет положительный RMSE.

`np.expm1()` применяется к предсказаниям, если нужны цены в исходной шкале. Применять его к готовым значениям RMSE нельзя.

После завершения выбранных моделей таблица выводится в терминал и сохраняется в `results/results.csv`:

- `model` — имя модели; нейросеть записывается как `neural network`;
- `mean` — среднее RMSE по пяти фолдам;
- `std` — стандартное отклонение RMSE по фолдам;
- `fold1`–`fold5` — RMSE каждого фолда.

Значения округляются до трёх знаков. При повторном запуске строки выбранных моделей заменяются, остальные сохраняются. После изменения данных или способа оценки запускайте все модели заново, чтобы не сравнивать новые результаты со старыми.
